# Smart Home Energy Forecasting using LSTM

Forecast household electricity demand 15 minutes ahead from the previous 24
hours of readings. The project downloads and prepares the UCI Individual
Household Electric Power Consumption dataset, trains an LSTM, evaluates it on
a chronological holdout, and serves forecasts and energy-use insights in a
Streamlit dashboard.

## Features

- Automatic download and ingestion of the UCI dataset.
- Timestamp parsing, invalid-reading handling, 15-minute resampling, and
  missing-interval interpolation.
- Leakage-aware MinMax scaling and 96-reading sequence generation.
- Two-layer LSTM training with dropout, test metrics, and a loss plot.
- Recursive 15-, 30-, 45-, and 60-minute forecasts.
- Interactive history, forecast, daily energy, and current-versus-predicted
  Plotly charts.
- Threshold alerts and simple, dynamically selected energy-saving advice.

## Dataset

The source is the
[UCI Individual Household Electric Power Consumption dataset](https://archive.ics.uci.edu/dataset/235/individual+household+electric+power+consumption).
It contains minute-level readings from one household in Sceaux, France. The
target is `Global_active_power`, measured in kilowatts. The preprocessing
module downloads the UCI ZIP archive on first use and writes the source rows as
`data/household_power_consumption.csv`. The dataset is not committed to this
repository.

Minute-level readings are averaged into 15-minute bins. Thus, one day's input
contains 96 observations, and the target is the average kilowatt reading for
the next 15-minute bin. Daily energy in the dashboard is estimated by summing
each 15-minute average multiplied by 0.25 hours.

## Requirements

- Python 3.10 or newer
- pip
- Internet access on first run to download the dataset

TensorFlow installation support varies by operating system and processor. Use
a Python environment compatible with the TensorFlow package available for
your platform.

## Installation

From the project directory:

```bash
cd smart_home_energy_forecasting
python -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

On Windows PowerShell, activate the environment with:

```powershell
.venv\Scripts\Activate.ps1
```

## Train the model

Training downloads and preprocesses the dataset if needed, trains the LSTM,
evaluates the chronological test set, and saves the model, scaler, metrics,
and loss chart under `models/`.

```bash
python -m src.train_model
```

Training defaults to 20 epochs and a batch size of 32. Set `EPOCHS` or
`BATCH_SIZE` in the environment to change these values, for example:

```bash
EPOCHS=5 python -m src.train_model
```

## Run the dashboard

Train the model once, then start Streamlit:

```bash
streamlit run app.py
```

The app shows the latest measured power, a selectable forecast horizon,
estimated daily energy, peak power, test-set MAE/RMSE/R², and the associated
interactive charts. The sidebar controls the high-consumption threshold and
history window. A warning appears when the selected forecast exceeds the
threshold.

## Model architecture

The model is a Keras `Sequential` network:

1. `LSTM(64, return_sequences=True)`
2. `Dropout(0.2)`
3. `LSTM(32)`
4. `Dropout(0.2)`
5. `Dense(16, activation="relu")`
6. `Dense(1)`

It uses Adam, mean squared error loss, mean absolute error as a training
metric, and a chronological validation split from the training sequences.
Holdout MAE, RMSE, and R² are calculated in the original kW units.

## Future improvements

- Add weather, calendar, and occupancy data as exogenous model features.
- Compare against seasonal naive, tree-based, and probabilistic forecasting
  baselines.
- Add rolling-origin evaluation, automated retraining, and data-drift
  monitoring.
- Persist forecasts and observed values to support production monitoring.
- Add household-specific alert thresholds and user-configurable advice.

## Limitations

This dataset describes a single household and historical period. It is useful
for demonstrating forecasting workflows, but it does not establish
performance for other homes or guarantee real-world savings. Treat forecasts
and recommendations as informational.
